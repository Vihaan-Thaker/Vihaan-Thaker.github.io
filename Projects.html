Single Image Super-Resolution via Residual CNNs

Course Project: ME228 | IIT Bombay | Jan '26 - Apr '26

  • Engineered an end-to-end deep learning pipeline for Single Image Super Resolution (SISR), an ill-posed computer vision problem to reconstruct sharp high-resolution images from a single low-resolution input via learned patterns.
  • Built a residual CNN with 32 skip-connection blocks, training on Sen2Venus & DIV2K dataset using L1 loss.
  • Achieved 34.84 dB PSNR and 0.94 SSIM at ×2 upscaling, outperforming the bicubic baseline by +3.6 dB PSNR.
